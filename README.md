# SE4050 Deep Learning 2026 — Road-Damage Classification (Group Project)

Road-damage type classification on the **RDD2020** dataset, comparing four CNNs
under identical data, splits and training conditions:

| Model | Task | Owner | Notebook |
|---|---|---|---|
| Custom CNN | multi-label damage classification (full images, from scratch) | IT23331518 | [notebooks/IT23331518/custom_cnn.ipynb](notebooks/IT23331518/custom_cnn.ipynb) |
| VGG16 | multi-label damage classification (full images) | IT22064868 | [notebooks/IT22064868/VGG_16.ipynb](notebooks/IT22064868/VGG_16.ipynb) |
| ResNet50 | multi-label damage classification (full images) | IT23325814 | [notebooks/IT23325814/ResNet50.ipynb](notebooks/IT23325814/ResNet50.ipynb) |
| MobileNetV2 | multi-class damage classification (bounding-box crops) | IT22063564 | [notebooks/IT22063564/mobilenetv2_training.ipynb](notebooks/IT22063564/mobilenetv2_training.ipynb) |

Classes (official RDD2020 label map): **D00** longitudinal crack, **D10**
transverse crack, **D20** alligator crack, **D40** pothole. Other tags found in
the XMLs (`D01`, `D44`, …) are dropped.

## 1. Dataset — where the folders must go

The dataset is **not** committed (see `.gitignore`). Download it from
<https://data.mendeley.com/datasets/5ty2wb6gvg/1> and extract the archives so
that **this exact structure exists under `data/`** (relative to the repository
root — the notebooks will not find anything elsewhere):

```
SE4050-Deep-Learning-Assignment/
`-- data/
    |-- Dataset_Source.txt            dataset link + full structure notes
    |-- train/                        <- RDD2020 "train" archive
    |   |-- label_map.pbtxt           D00/D10/D20/D40 class map (not read by code)
    |   |-- Czech/
    |   |   |-- images/               *.jpg   (2,829 images, all annotated)
    |   |   `-- annotations/xmls/     *.xml   Pascal-VOC damage boxes
    |   |-- India/
    |   |   |-- images/               *.jpg   (7,706 images, all annotated)
    |   |   `-- annotations/xmls/     *.xml   Pascal-VOC damage boxes
    |   `-- Japan/
    |       |-- images/               *.jpg   (2,607 images)
    |       `-- annotations/xmls/     MAY BE MISSING - normal, skipped with a warning
    |-- test1/                        <- RDD2020 "test1" archive (images only)
    |   |-- Czech/  {images/ , annotations/}    no damage *.xml - expected
    |   |-- India/  {images/ , annotations/}
    |   `-- Japan/  {images/ , annotations/}
    |-- test2/                        <- RDD2020 "test2" archive (same as test1/)
    `-- processed/                    GENERATED by the MobileNetV2 pipeline only
        |-- crops/train/{D00,D10,D20,D40}/    *.jpg  224x224 square crops
        |-- crops/val/  {D00,D10,D20,D40}/
        |-- crops/test/ {D00,D10,D20,D40}/
        |-- splits.csv                one row per crop
        `-- dataset_summary.json      crop counts
```

Rules of thumb:

* Images always live in `<split>/<country>/images/*.jpg`.
* Labels are Pascal-VOC XMLs in `<split>/<country>/annotations/xmls/*.xml`
  (file stem must match the image stem).
* `test1/`, `test2/` and `train/Japan` ship **without** damage annotations —
  the notebooks warn and skip them; that is not an error.
* Do **not** create `data/processed/` by hand — it is generated (step 5).

## 2. Environment setup (once per machine)

Requirements: **Python 3.11**, ~4 GB free disk. TensorFlow ≥ 2.11 has no GPU
support on native Windows, so everything runs on CPU (the pipelines are built
for that: frozen backbones, cached features, early stopping).

```powershell
# 1. clone and enter the repository
git clone <repo-url>
cd SE4050-Deep-Learning-Assignment

# 2. virtual environment
python -m venv venv
.\venv\Scripts\Activate.ps1

# 3. dependencies (verified: pip check clean, TF 2.21.0)
pip install -r requirements.txt

# 4. VGG16 path/hyper-parameter overrides
Copy-Item .env.example .env

# 5. Jupyter kernel used by every command below
python -m ipykernel install --user --name se4050-venv
```

Activate the environment (`.\venv\Scripts\Activate.ps1`) before running any
command below. All commands are run **from the repository root** (the notebooks
walk up to it themselves, so starting Jupyter from the root also works).

## 3. How to run each notebook (step by step)

Every notebook is self-contained (config, validation and split code inside) and
can be run either interactively or headless.

### Run order (fresh clone)

```
1. VGG_16.ipynb          -> creates the shared split manifest (required by 2 and 3)
2. ResNet50.ipynb        -> cross-checks that manifest
3. custom_cnn.ipynb      -> aborts if the manifest MD5 differs
4. mobilenetv2_training.ipynb  -> independent (needs the crops, see step 5)
```

The manifest `results/IT22064868/metrics/split_manifest.csv` stores
**absolute image paths**, so it only works on the machine that generated it.
On a new PC, always run VGG first to regenerate it.

### Option A — interactive (JupyterLab)

```powershell
jupyter lab          # from the repository root, then open the notebook
```

Kernel: **`se4050-venv`** (Kernel → Change kernel → se4050-venv), then
**Run → Run All Cells** and wait for `outputs -> results/<id>` in the last cell.

### Option B — headless (PowerShell, one notebook at a time)

```powershell
# 1) VGG16  (owner IT22064868) — features cached, training skipped if the checkpoint matches; ~5 min re-run
python -m nbconvert --to notebook --execute --inplace notebooks\IT22064868\VGG_16.ipynb `
    --ExecutePreprocessor.kernel_name=se4050-venv --ExecutePreprocessor.timeout=7200

# 2) ResNet50  (owner IT23325814) — feature cache hit + head training skipped; ~5 min re-run
python -m nbconvert --to notebook --execute --inplace notebooks\IT23325814\ResNet50.ipynb `
    --ExecutePreprocessor.kernel_name=se4050-venv --ExecutePreprocessor.timeout=7200

# 3) Custom CNN  (owner IT23331518) — trains from scratch if weights are missing (~30 min CPU),
#    otherwise loads the checkpoint; ~5 min re-run
python -m nbconvert --to notebook --execute --inplace notebooks\IT23331518\custom_cnn.ipynb `
    --ExecutePreprocessor.kernel_name=se4050-venv --ExecutePreprocessor.timeout=7200

# 4) MobileNetV2  (owner IT22063564) — ALWAYS retrains (no checkpoint skip), CPU, allow up to 6 h
python -m nbconvert --to notebook --execute --inplace notebooks\IT22063564\mobilenetv2_training.ipynb `
    --ExecutePreprocessor.kernel_name=se4050-venv --ExecutePreprocessor.timeout=21600
```

Run them **one after another, never in parallel** (15 GB RAM / CPU-only).
Execution finishes without errors when each notebook prints
`outputs -> results/<id>` at the end.

### What each notebook does, cell group by cell group

**1. `notebooks/IT22064868/VGG_16.ipynb` (run this first)**
1. Config + project-root walk (`os.chdir` to the repo root) and `.env` overrides.
2. Scans `data/train`, `data/test1`, `data/test2` (corruption + duplicate check).
3. Parses the Czech/India VOC XMLs → label table → **writes the shared split
   manifest** `results/IT22064868/metrics/split_manifest.csv` (reused if it
   already matches).
4. EDA figures → frozen VGG16 feature extraction (cached in
   `results/IT22064868/cache/`) → head training (skipped when
   `src/IT22064868/models/vgg16_multilabel.keras` + run_meta match).
5. Test evaluation @0.5 and at validation-tuned thresholds → metrics, ROC,
   confusion matrices, `results/IT22064868/metrics/*`.
6. Final section includes **“Classify a new image”** — swap
   `image_path = test_paths[0]` for your own photo.

**2. `notebooks/IT23325814/ResNet50.ipynb`**
1. Same config/scan/XML validation as VGG.
2. Recomputes the split and **cross-checks it against the VGG manifest**
   (recorded in `shared_manifest_check.json`).
3. ResNet50 backbone feature extraction (cached in `results/IT23325814/cache/`).
4. Head training — skipped when `src/IT23325814/models/resnet50_multilabel.keras`
   and the run meta already match.
5. Evaluation @0.5 + tuned thresholds → `results/IT23325814/{metrics,figures,tables}`.
6. Ends with **“Classify a new image”**.

**3. `notebooks/IT23331518/custom_cnn.ipynb`**
1. Reads the shared manifest (does **not** parse the XMLs itself) and
   **aborts** if its split MD5 ≠ `5fac8fa95389101fde12da21ab93388b`.
2. Leakage checks (cluster-level split, duplicate paths).
3. Trains the Custom CNN from scratch (~30 min CPU, 21 epochs, early
   stopping) unless `results/IT23331518/custom_cnn_model.keras` matches the
   config — then the weights are loaded instead.
4. Evaluation @0.5 + validation-tuned thresholds → `results/IT23331518/*`.
5. Ends with **“Classify a new image”**.

**4. `notebooks/IT22063564/mobilenetv2_training.ipynb`**
1. Colab-only cells (git clone / Drive) are skipped locally.
2. **Data:** uses `data/processed/crops/` if present, else unzips
   `data/IT22063564_processed.zip` (Colab: `MyDrive/data/processed.zip`), else
   rebuilds the crops by calling `src/IT22063564/prepare_data.py`.
3. **Train:** shells out to `src/IT22063564/train.py` (two-phase transfer
   learning, 10 + ≤20 epochs). **This always retrains** — re-running it
   produces new numbers.
4. **Evaluate:** `src/IT22063564/evaluate.py` → test metrics, classification
   report, ROC/confusion figures, `tables/model_comparison.csv`.
5. Colab-only: copies results to Drive.

## 4. Dataset

- **RDD2020: Road Damage Dataset 2020** — Arya, D. et al., *Data in Brief* 36
  (2021) 107133, doi:10.1016/j.dib.2021.107133. Licence: CC BY 4.0.
  Download: https://data.mendeley.com/datasets/5ty2wb6gvg/1 (or
  https://github.com/sekilab/RoadDamageDetector)
- Road photos from Czech Republic, India and Japan with Pascal-VOC bounding
  boxes.

Validation facts (recorded by every notebook into `results/<reg>/metrics/`):

* 13,142 train images; 1 corrupt file (`Japan_004643.jpg`) is detected and
  skipped, leaving 13,141 usable images.
* 10,535 annotated train images (Czech + India); **4,295** carry at least one
  of the four target classes — these form the labelled multi-label set
  (1,300 of them have more than one damage type).
* `test1`/`test2` and the Japan train images ship without damage annotations
  and are description-only; all reported metrics use the held-out **test**
  split of the labelled set (or of the crops carved from it).

**Task framing.** VGG16, ResNet50 and the custom CNN classify the full image
(multi-label, sigmoid + BCE) on the same shared split manifest — the backbones
use frozen ImageNet features, the custom CNN learns everything from scratch.
MobileNetV2 classifies square crops around each bounding box
(15% context, 224×224, multi-class softmax); its labelled test set is carved
out of `train` **by source image** so crops from one photo never cross splits.

## 6. Shared methodology

* Single global seed **42** (Python / NumPy / TensorFlow).
* VGG16, ResNet50 and the custom CNN use the **same labelled set and the same
  split algorithm** (64-bit dHash near-duplicate clusters assigned as whole units,
  70/15/15). ResNet50 re-computes the split and cross-checks it against the
  shared manifest `results/IT22064868/metrics/split_manifest.csv`
  (agreement is saved to `results/IT23325814/metrics/shared_manifest_check.json`);
  the custom CNN aborts unless it re-derives the same manifest MD5
  (`5fac8fa95389101fde12da21ab93388b`).
* Threshold tuning happens on **validation only**; the test set is touched
  once, in the final evaluation cells (assignment rule).
* TensorFlow oneDNN CPU kernels may cause tiny numeric variation between runs;
  bit-level reproducibility is not claimed.
